# Guía de Contribución

¡Gracias por querer mejorar este proyecto! Sigue estas reglas sencillas antes de enviar cambios.

## Cómo reportar un error
Si encuentras un fallo en la API o en las tareas, abre un **Issue** en GitHub indicando:
1. Qué acción estabas realizando cuando ocurrió el error.
2. El resultado esperado frente al error obtenido.

## Cómo proponer una mejora
Si deseas agregar una nueva funcionalidad, abre un **Issue** explicando tu propuesta antes de programar para revisarla juntos.

## Checklist antes de enviar un Pull Request
Antes de subir tus cambios, verifica todo esto:

- [ ] Probé el código localmente y funciona sin errores.
- [ ] Trabajé en una rama nueva y no directamente en `main`.
- [ ] Actualicé el `README.md` si agregué nuevas funciones o requisitos.
